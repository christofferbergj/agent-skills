## Local adaptations to preserve

- The [library-wide adaptations](../../agents/maintain-skills/references/ADAPTATION.md#library-wide-adaptations) apply; this list holds only this skill's own divergences.
- Charts and diagrams come from the host's available tools where upstream names Cursor's `/visualize`, and a host that cannot render a visual gets a link to the artifact or plain text. Reason: `/visualize` does not exist in Codex or Claude Code, and a terminal host cannot render images inline.
- The catch-up covers the chat since the user's last message before this invocation, not before `/ketchup`, and keeps the catch-up, not the whole turn, read-only. Reason: the skill is model-invoked by the library-wide Pstack adaptation, so it can run mid-turn with no `/ketchup` message.
