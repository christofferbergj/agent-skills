### Local adaptations to preserve

Adopted principles: cross-provider critics run as tracked T3 child tasks; `orchestrator_capabilities` runs once per thread, before the first `delegate_task`; every call names the model and effort; the brief is the child's whole context and passes files by absolute path; a stable `clientRequestId` per task; read-only critics in plan mode; a critic returns findings as its final message, and a writer returns a short report naming a file; a failed optional critic is reported, and the work continues without it.

Departures: the counterpart's model, effort, and speed come from `scripts/target.py`, which reads the personal configuration and the remaining Codex usage, not a role table of writers and sketchers; a usage-limit failure skips the retry and every route on that vendor's account; a new key for each retry attempt; collection through a repeated `wait` call; T3 is the first of three routes, ahead of the CLI wrapper and a native critic; Oliver's owner threads, coordinator workers, children on his other machines, report-file paths, thread-paging rules, and eval players are left out.

Decide upstream changes to these files by the principle-derived rules. The 2026-10-20 import adapted the T3 section and guide; plan-mode children of both vendors and a repeated `wait` call collecting an async child were exercised in T3 Code, and the CLI wrapper's model and effort flags pass unit tests and a preflight on both real CLIs.
