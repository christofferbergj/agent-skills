# Maintain skills

Adopts upstream changes from Pstack, Matt Pocock, Thermos, and OpenClaw, plus the ideas behind its Oliver Cederborg-derived skills, into this library while keeping its light local adaptations, and audits every skill in rotation. Uses subagents, records decisions in each skill's provenance, asks the owner through its PRs, and carries unfinished work to the next run.

Install `/writing-for-agents`, `/swarm`, and `/pr` with it.
