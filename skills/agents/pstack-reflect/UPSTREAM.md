## Local adaptations to preserve

- The [library-wide adaptations](../../agents/maintain-skills/references/ADAPTATION.md#library-wide-adaptations) apply; this list holds only this skill's own divergences.
- The reviewer templates recognize skill use through actual file or command reads, explicit invocation, supplied delegate briefs, and documented commands at resolved source or installed paths, and say a catalog listing alone does not establish use. Codex and Claude Code put every installed skill's description in context, so a skill named in the transcript was not necessarily used.
- Approved edits go to the skill's source repository, never the installed copy. Installs are Skills CLI snapshots that the next refresh overwrites.
- Step 1 matches the opening prompt past host-injected context instead of the first JSONL line. Codex records the AGENTS.md instructions as each session's first user message, so a first-message match never finds the conversation there and always falls back to a digest.
