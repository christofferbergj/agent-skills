## Local adaptations to preserve

- The [library-wide adaptations](../../agents/maintain-skills/references/ADAPTATION.md#library-wide-adaptations) apply; this list holds only this skill's own divergences.
- Edits go to the skill's source, the repository /pstack-setup records or the one it was installed from, never the installed copy, in place of upstream's `plugins/cache/` and `.cursor/skills/` rule. Installs are Skills CLI snapshots that the next refresh overwrites.
- The transcript is found through the host's active conversation API or /recall, matching the opening prompt past host-injected context. Upstream's "Read the whole transcript" relies on Cursor naming its `agent-transcripts/` directory in the system prompt, which Codex and Claude Code don't do, and Codex records the AGENTS.md instructions as each session's first user message, so a first-message match never finds the conversation.
- Approved edits go through /writing-for-agents, Matt Pocock's owner of skill writing and mechanics.

## Maintenance

Invoke `/maintain-skills` for repository-wide upkeep, including this suite's supporting files and shared consumers. Reinstalling from this repository refreshes the adaptation; it does not merge Cursor's originals.

Keep the original import fixed. Advance the reviewed-through baseline only after the relevant delta is fully resolved and checks pass. Record adopted, adapted, and excluded changes and their reasons.
