## Local adaptations to preserve

- The [library-wide adaptations](../../agents/maintain-skills/references/ADAPTATION.md#library-wide-adaptations) apply; this list holds only this skill's own divergences.
- A skill counts as used when the transcript shows its file or a documented command read, its explicit invocation, or a delegate brief that supplied it; its description in the host's skill listing alone does not count. Codex and Claude Code put every installed skill's description in context, so a skill named in the transcript was not necessarily used, and upstream's "routes to a skill the session used" needs that test here.
- Approved edits go to the skill's source repository, never the installed copy, in place of upstream's `plugins/cache/` and `.cursor/skills/` rule. Installs are Skills CLI snapshots that the next refresh overwrites.
- When the conversation is no longer whole in context, the transcript is found through the host's active conversation API or /recall, matching the opening prompt past host-injected context, and never by globbing every project's sessions. Upstream says only "Read the whole transcript"; on these hosts a compacted conversation needs a way to reach it, Codex records the AGENTS.md instructions as each session's first user message so a first-message match never finds the conversation, and a cross-project glob reads unrelated private chats.
- Approved edits to a skill go through /writing-for-agents, which owns skill mechanics, where upstream edits them directly.

## Maintenance

Invoke `/maintain-skills` for repository-wide upkeep, including this suite's supporting files and shared consumers. Reinstalling from this repository refreshes the adaptation; it does not merge Cursor's originals.

Keep the original import fixed. Advance the reviewed-through baseline only after the relevant delta is fully resolved and checks pass. Record adopted, adapted, and excluded changes and their reasons.
