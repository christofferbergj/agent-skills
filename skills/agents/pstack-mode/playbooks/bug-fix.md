# Bug fix

Own the discriminating reproduction and the root-cause fix. Delegate investigation and the fix to subagents and stay in the lead.

Be scientific. Every shipped line traces to runtime evidence. Belt-and-suspenders that "might help" is a hypothesis, not a fix. It does not ship. When evidence refutes a hypothesis, revert what it motivated. The smallest change the evidence justifies ships, nothing more.

1. Invoke /diagnosing-bugs for the shared reproduction and diagnosis loop, using the remaining steps as Pstack evidence and delivery coverage rather than a second diagnosis. Reproduce it yourself on the affected surface before editing, even when a debug or instrumentation protocol says to ask the user to reproduce. Ask the user only with a stated, specific reason the control surface cannot reach the target, and only after driving it as far as it goes. Distinguish similar failures with the actual inputs, state, timing, or trace. Complete when the original failure is observed or the missing prerequisite is explicit.
2. Binary-search the cause. Seed candidate hypotheses with /pstack-how over the affected subsystem and /pstack-why for regression history, then rule them out until one survives, taking the split that cuts the most remaining problem space each pass. When program state is unclear, add instrumentation or logging and read it as the code runs. Don't guess. Trace the first violated contract and invoke /pstack-principle-fix-root-causes. Complete when runtime evidence confirms the surviving mechanism.
3. Plan the fix. If it crosses a function boundary, use /pstack-architect first. Delegate implementation through /pstack-swarm to a subagent on your configured bug-fix role with a specific scope. Remove the causal defect rather than masking an invalid state. Complete when the original reproduction passes and neighboring contracts hold.
4. Verify on the same surface: re-run the same user path and relevant tests, preserve failing/passing evidence, and inspect indirect effects through /pstack-blast-radius when appropriate. "Inconclusive" or wrong-surface is not a pass; flag it. Unit tests show branch behavior, not bug absence. Complete when the fix is proved on the actual artifact or the limitation is recorded.
5. Stage the commits so the failing repro lands before the fix in git history, per /pstack-principle-sequence-verifiable-units. Use /pstack-tdd for the failing-test-first cadence when the bug has a cheap local test path; skip it when the test would be expensive, integration-heavy, or unclear. Complete when history shows the failing repro before the fix, or the skip reason is recorded.
6. Review the diff through /review-loop and follow Opening a PR when authorized. Complete when the report distinguishes reproduced facts, causal inference, and unverified cases.

Return what was broken, the root cause, the fix, how you verified it, regression coverage, and outstanding gaps. Paste failing-then-passing repro output verbatim.
