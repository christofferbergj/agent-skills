# Visual parity

Own observable equivalence on the specified surfaces.

1. Identify the reference and target builds, routes, states, viewport, fonts, data, and interaction sequences. Complete when captures compare the same inputs and environment.
2. Capture the reference and define the parity metric or review predicate. Keep baseline evidence immutable. Complete when the expected output and allowed differences are concrete.
3. Implement the migration or correction in isolated units, using /pstack-swarm for independent surfaces and /pstack-architect for consequential boundaries. Complete when changed states can be driven through the actual interface.
4. Drive every scoped state, compare captures, and investigate meaningful differences. Include responsive and interaction states from the contract. Complete when parity is demonstrated or every remaining mismatch is reported.
5. Check behavior, inspect the diff, and follow Opening a PR when authorized. Complete when proof applies to the final artifact and survives cleanup.

Return reference/target revisions, states, captures or diffs, behavioral checks, and remaining mismatches.
