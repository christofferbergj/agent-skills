# Investigation

Own the cited answer. The deliverable is an explanation, not a code change.

1. Frame the target and question from repository context. Invoke /pstack-how for behavior and placement, /pstack-why for rationale, or both when the distinction matters. Complete when the question and relevant boundaries are concrete.
2. Gather primary evidence with the available source and runtime tools. A read-only investigation can use an existing executable probe; it does not authorize building a new feature. Label measured, inferred, and unknown claims. Complete when the answer has traceable evidence and named gaps.
3. Reconcile contradictory sources, explain the implications, and return the answer with citations and uncertainty. Complete when each material claim has support and any further action is a separate proposal.

Return the answer, evidence, confidence, and unresolved questions. Open a PR only if the user separately requested a source artifact or change.
