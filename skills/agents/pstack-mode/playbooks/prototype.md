# Prototype

Own the experiment that settles an empirical fork.

1. State the question and the observation that distinguishes the options. Read existing conventions first. Complete when the experiment can resolve something the user should not have to guess.
2. Invoke /design-prototype for the shared logic-demo or UI-experiment artifact and its retained decision. Build the smallest isolated sketch, using /pstack-arena for materially different alternatives and /pstack-swarm for independent work. Keep prototype scope separate from production acceptance. Complete when each option can be observed under comparable conditions.
3. Drive the real surface or executable probe, capture outputs, and compare against the stated predicate. Complete when the observation supports a choice or demonstrates that the probe cannot distinguish it.
4. Reconcile accepted model changes through /domain-modeling. Explain the result, limitations, and whether the prototype is discarded or intentionally promoted. Complete when production work has a grounded decision and no prototype scaffolding is mistaken for finished implementation.

Return the question, artifacts, observations, choice, and unresolved limitations. A genuine product preference remains the user's decision.
