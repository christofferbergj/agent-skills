# Evaluate a skill or workflow

Own behavioral evidence rather than a persuasive prompt diff.

1. Define the question, realistic tasks, acceptance rubric, comparison arms, and cost or runtime budget. Keep hidden grading criteria separate from candidate prompts. Complete when a trial can discriminate the behavior being changed.
2. Prepare isolated, sanitized fixtures with raw inputs rather than the suspected answer. Run baseline and candidate arms through /pstack-swarm where useful. Record actual host/model and revisions. Complete when every trial has comparable conditions and independent output.
3. Grade transcripts and artifacts against the predefined behavior, including failed runs, skipped tools, and work actually performed. Complete when each score has evidence and missing trials remain gaps.
4. Analyze variance, cost, and failure classes before promoting the change. Invoke /pstack-benchmark-checklist for measured claims. Complete when the conclusion is supported or the experiment is declared inconclusive.

Return method, trial evidence, actual models, comparative results, confidence, and the promotion or rejection decision.
