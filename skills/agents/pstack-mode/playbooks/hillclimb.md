# Hillclimb

Own scientific progress on one metric within an agreed budget.

1. Define the target, baseline, comparable workload, correctness gate, and run limits. Invoke /pstack-benchmark-checklist. Complete when an improvement cannot be manufactured by doing less work or hiding errors.
2. Keep a hypothesis queue and use /pstack-show-me-your-work. Test one bounded change at a time; use /pstack-swarm for isolated independent experiments. Complete each trial when evidence accepts or rejects the hypothesis.
3. Keep accepted improvements as verifiable units and revert rejected experiments. Revisit the premise when repeated approaches fail. Complete each checkpoint when the best known artifact and evidence are durable.
4. Stop at the target, agreed limit, or an evidenced dead end that needs a decision. Preserve a partial result without relaxing the target. Complete when remaining hypotheses and the resumption path are explicit.

Return baseline, accepted wins, rejected hypotheses, method, correctness, current metric, and remaining work.
