# Skills

Browse by the job you want to do. Each category lists the available skills with a one-line description.

| Category                                            | What belongs here                                                                      |
| --------------------------------------------------- | -------------------------------------------------------------------------------------- |
| [Agent workflows](agents/README.md)                 | Configure agents, coordinate work, maintain skills, and learn from completed sessions. |
| [Planning and design](planning/README.md)           | Understand a codebase, research a problem, clarify requirements, and choose a design.  |
| [Implementation and tooling](engineering/README.md) | Build and debug software, configure development tools, and verify behavior.            |
| [Reviews](reviews/README.md)                        | Assess code, architecture, tests, UI, performance claims, and the effects of a change. |
| [Writing and explanation](communication/README.md)  | Explain work clearly, write technical documents, and edit prose.                       |
| [Principles](principles/README.md)                  | Design and coding principles selected by the workflows.                                |

Each skill keeps its `SKILL.md`, host metadata, references, scripts, assets, and source records together. Category moves do not change its invocation name.

For new skills and repository checks, see [Contributing](../CONTRIBUTING.md). For usage and required installation companions, see the [main README](../README.md).
