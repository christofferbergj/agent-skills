## Local adaptations to preserve

- The [library-wide adaptations](../../agents/maintain-skills/references/ADAPTATION.md#library-wide-adaptations) apply; this list holds only this skill's own divergences.
- The comparison of shapes uses /codebase-design's vocabulary: that skill is the shared owner of depth and seam reasoning, and its design-it-twice guidance relies on this skill invoking it and folds its constraints into this run instead of starting a second arena.
- Behavior tests at the chosen shape's public seams go through /tdd when a practical test path exists: /tdd is the shared owner of behavior-test discipline, and this skill still writes the production code against those seams.
- The approved-interface gate: once the user has approved a shape, an incompatible change to it goes back to them before more code builds on it. [ADR 0001](../../../docs/adr/0001-maintain-an-owned-pstack-adaptation.md) requires pausing when an approved interface changes, and /pstack-mode and its playbooks rely on the gate; upstream redesigns without asking.
