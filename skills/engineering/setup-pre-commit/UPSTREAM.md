## Local adaptations to preserve

- The [library-wide adaptations](../../agents/maintain-skills/references/ADAPTATION.md#library-wide-adaptations) apply; this list holds only this skill's own divergences.
- `references/DEFAULT-SETUP.md` keeps an existing `prepare` script by appending Husky after it, because `husky init` overwrites the script, and its checklist covers only the parts the setup installed.
- Reuse the project's formatter, hooks, and checks instead of forcing Prettier. Preserve staging state, merge existing configuration, and prove the hook with a harmless scoped fixture.
- `SKILL.md` is a four-step existing-toolchain process; upstream's Husky, lint-staged, and Prettier steps and notes live in the local-only [`references/DEFAULT-SETUP.md`](references/DEFAULT-SETUP.md) in upstream wording, followed only for the tools a repository lacks. That file detects Bun's text `bun.lock` (the default since Bun 1.2) beside upstream's `bun.lockb`, and commits only when authorized.
