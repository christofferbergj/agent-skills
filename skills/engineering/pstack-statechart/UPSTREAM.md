## Local adaptations to preserve

- The [library-wide adaptations](../../agents/maintain-skills/references/ADAPTATION.md#library-wide-adaptations) apply; this list holds only this skill's own divergences.
- Namespace: `statechart` maps to `pstack-statechart`.
- Invocation: model-invoked, where upstream sets `disable-model-invocation: true`. The contract makes Pstack helpers model-invoked, and this skill is not one of its user-invoked entrypoints or outward-effect skills: it writes only to a scratch folder outside the repository. The description is rewritten in the Pstack-scoped helper style and names four branches: showing how a system moves between states, showing a bug as a path through states, chart to TLA+ skeleton, and auditing code against an existing spec. The second branch keeps upstream's "show a bug as a path" trigger, and upstream's `/statechart` trigger is covered by typing `/pstack-statechart`. Upstream's description of each bug as a numbered path with blue borders is in `scripts/statechart.mjs --help`, which the body sends the agent to for reading a chart.

## Maintenance

Invoke `/maintain-skills` for repository-wide upkeep, including this suite's supporting files and shared consumers. Reinstalling from this repository refreshes the adaptation; it does not merge Cursor's originals.

`scripts/` is upstream's tree copied verbatim. On an upstream change, copy the tree again, run `npx oxfmt` on it, and run `node --test skills/engineering/pstack-statechart/scripts/test/*.test.mjs`, which is upstream's command. `pnpm check` discovers only `*.test.ts` files, so it does not run this suite. Tests that need TLC install it with mise on first run, unless `TLA2TOOLS` and `JAVA` name a TLC and Java to use.

Keep the original import fixed. Advance the reviewed-through baseline only after the relevant delta is fully resolved and checks pass. Record adopted, adapted, and excluded changes and their reasons.
