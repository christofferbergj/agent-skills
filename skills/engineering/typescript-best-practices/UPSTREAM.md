## Local adaptations to preserve

- The [library-wide adaptations](../../agents/maintain-skills/references/ADAPTATION.md#library-wide-adaptations) apply; this list holds only this skill's own divergences.
- A duration stored as a plain number still admits negative, infinite, and `NaN` values, so upstream's start-plus-duration `TimeRange` example, which claims a negative range can't be written, is replaced by a note that the constraint needs boundary validation; the `SKILL.md` row drops that example and its `rangeEnd()` helper, keeping upstream's other wording.
- The `satisfies` guidance defines the example's `Config` and says contextual typing still decides literal inference, because upstream's claim that `satisfies` never widens literals is false for a property typed `string` or `number`, such as its own `cols`.
- The non-empty tuple example reads the guaranteed first entry, because upstream's random index fails with TS2322 under `noUncheckedIndexedAccess`.
- Drops upstream's `paths: ["**/*.ts", "**/*.tsx"]`: /principle-type-system-discipline loads it for TypeScript examples whatever files are open, and Codex has no path activation, so the description scopes it to TypeScript design work in Pstack tasks.
- Wire formats follow the protocol's compatibility rules, because JSON-RPC has no protocol-wide `ignoreUnknownFields`. The object-args counterexample names its real fault, a positional `uri` mixed with named options, because swapping its two differently typed arguments does not compile.
