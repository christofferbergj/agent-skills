## Local adaptations to preserve

- The [library-wide adaptations](../../agents/maintain-skills/references/ADAPTATION.md#library-wide-adaptations) apply; this list holds only this skill's own divergences.
- Invocation: model-invoked, where upstream sets `disable-model-invocation: true`. The contract makes Pstack helpers model-invoked, and this skill is not one of its user-invoked entrypoints or outward-effect skills: it writes only to a scratch folder outside the repository. The description is rewritten in the Pstack-scoped helper style and names upstream's two branches: checking a TLA+ model of how a system moves between states and drawing it as a Mermaid statechart with the shortest path to each broken rule, and showing a bug as a path through states. Upstream's `/statechart` trigger is the skill's own name.

## Maintenance

Invoke `/maintain-skills` for repository-wide upkeep, including this suite's supporting files and shared consumers. Reinstalling from this repository refreshes the adaptation; it does not merge Cursor's originals.

`scripts/` and `references/render.md` are upstream's files copied verbatim. On an upstream change, copy them again, keep the launcher `scripts/statechart` executable, and run `npx oxfmt` on the skill. The formatter rewraps one line of `scripts/frontends/messages.ts` and the CSS rules in `references/render.md`. The root `.prettierignore` keeps it off `scripts/test/corpus/**/report.md`, which upstream's corpus test compares byte for byte. `scripts/check.sh` excludes `scripts/`, because the suite needs fast-check, TLC, and Java, which the repository does not provide. Run upstream's suite, `npm test` in `scripts/`, from a copy of the skill outside the repository with `fast-check@4.5.3` installed there, and with `TLA2TOOLS` and `JAVA` naming a TLC and Java; without them, the TLC tests skip. `mise install java@temurin-25` and the `http:tla2tools` tool that `scripts/run.ts` pins provide both.

Keep the original import fixed. Advance the reviewed-through baseline only after the relevant delta is fully resolved and checks pass. Record adopted, adapted, and excluded changes and their reasons.
