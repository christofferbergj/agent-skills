# Agent skills

This repository maintains one skill library derived from multiple upstream sources.

## Language

**Upstream Pstack**:
Poteto's original collection of coding workflows, published in Cursor's plugins repository.

**Pstack adaptation**:
The version of Pstack owned and maintained in this repository for the user's workflows.

**Pstack mode**:
The coordinated use of the Pstack adaptation in a conversation, distinct from using an individual helper.

**Combined library**:
The owned set of skills maintained and installed from this repository, with shared behavior across source families.

**Source family**:
Skills derived from one upstream collection, tracked together without defining a separate user workflow.

**Artifact owner**:
The skill responsible for a project document's meaning and update rules, regardless of the workflow that resolved the change.

**Source record**:
A skill-local record of its upstream identity, immutable import history, completed reviews, and intentional adaptations.
