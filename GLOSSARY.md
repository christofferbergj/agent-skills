# Agent skills

This repository distinguishes Poteto's original Pstack suite from the adaptation maintained here.

## Language

**Upstream Pstack**:
Poteto's original collection of coding workflows, published in Cursor's plugins repository.

**Pstack adaptation**:
The version of Pstack owned and maintained in this repository for the user's workflows.

**Pstack mode**:
The coordinated use of the Pstack adaptation in a conversation, distinct from using an individual helper.
